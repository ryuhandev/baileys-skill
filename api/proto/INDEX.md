# Protobuf reference (proto namespace)

Mirrored from https://baileys.wiki/proto-reference/... — generated from WAProto.proto. Each protobuf message has: a class (runtime, with encode/decode/create/verify), an interface prefixed I (plain-object shape — usually what you want), and a namespace directory when it has nested types.

Per v7: only .create(), .encode(), .decode() (+ decodeAndHydrate()) remain as proto helpers. .fromObject() was removed — use .create().
